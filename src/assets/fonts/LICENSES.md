# Bundled font licences

The `woff2` files in this folder are the latin and latin-ext subsets of fonts served by Google Fonts,
downloaded by `scripts/fetch-fonts.mjs` so Mochi never contacts Google at runtime. Each family is
distributed under the SIL Open Font License, Version 1.1 (OFL), copyright the respective Project Authors
as listed in each family's Google Fonts page and upstream repository. The fonts are unmodified apart from
Google's subsetting and woff2 packaging.
